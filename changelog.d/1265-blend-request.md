- **Added: `BlendRequest`, one edge-blend request for rounds, laws, distances and bevels** (#1265).
  - A builder: `round(edges, r)`, `chamfer(edges, d)`, `edge(e, section)` and `chain(c, section)` add blends; `round_corner`, `chamfer_corner`, `setback` and `overflow` set the options, each defaulting as the call without it does. `BlendSection` names a section (`Round`, `RoundLaw`, `RoundDistances`, `DistanceLaws`, `Chamfer`); `Blend` and `Chamfer` convert to it.
  - `build`, `build_checked` (every refused edge, in request order), `build_partial`, and the readings `limit`, `largest` and `seat` with a `Vary` (`Scale`, a law station, or a station of either distance law).
  - Each call routes to the existing function that builds that request, with the arguments it takes today, so results and refusal texts are that function's own. A combination no function builds (a law under rolling corners, setbacks with bevels, a checked reading of mixed blends, a reading of rounds of several radii) is refused by name.
  - `ChamferCorner` implements `Default` (`Facet`). No existing function changes. The rules are in ADR 0001, amendment "the public request", and `docs/design/1265-fillet-request.md`.
