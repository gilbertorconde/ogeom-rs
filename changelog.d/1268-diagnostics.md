- **Changed: one diagnostics facility, `ogeom_core::diag`, in place of 14 `OGEOM_DEBUG_*` variables** (#1268).
  - Each area writes to a named `Channel`. All channels are off by default, and a probe on an off channel costs one atomic load. `OGEOM_DEBUG` names the channels to switch on (`OGEOM_DEBUG=sew,wire`, or `all`), or a host calls `diag::set_enabled`. `all` leaves out `bool-audit`, which runs a second fill and asserts, so that one has to be named.
  - Lines go to stderr by default. A host sends them elsewhere with `diag::set_sink`, and back to stderr with `diag::reset_sink`. Probes write with the `ogeom_core::diag!` macro. The facade exports the module and the macro as `ogeom::core::diag`.
  - The old variables are gone. Use the channel instead: `OGEOM_ARRANGE_DEBUG` → `arrange`, `OGEOM_BOOL_AUDIT_BOUNDS` → `bool-audit`, `OGEOM_DEBUG_DEFEATURE` → `defeature`, `OGEOM_DEBUG_DOMAIN` → `domain`, `OGEOM_DEBUG_EDGE` → `edge`, `OGEOM_DEBUG_RUNOUT` → `fillet`, `OGEOM_DEBUG_MASS` → `mass`, `OGEOM_MESH_DEBUG_REFINE` → `mesh`, `OGEOM_DEBUG_SEW` → `sew`, `OGEOM_DEBUG_STRANDS` → `strands`, `OGEOM_DEBUG_SWEEP` and `OGEOM_DEBUG_RING` → `sweep`, `OGEOM_DEBUG_WIRE` → `wire`. `OGEOM_MESH_DEBUG` is removed, with no replacement.
  - Library crates no longer print to stdout or stderr outside `diag`, and clippy now rejects a new `eprintln!`, `println!` or `dbg!` in library code. `OGEOM_THREADS` is unchanged.
